# Unity Vision Pro 完整复刻开发计划

所有视觉与交互以当前 Unity 主场景及其依赖为准。阶段交付不代表删减最终范围。

| 阶段 | 实施内容 | 完成条件 |
|---|---|---|
| 1 工程与基线 | 原生工程、空间生命周期、Unity 依赖与参数提取、核心状态机 | 双 SDK 构建、状态转换测试通过；逐项记录尚未验收的视觉 |
| 2 开场与选关 | 原视频、透明材质、空间按钮、语言与感官袋分支、岛屿轮播 | 与 Unity 相同位置、尺度、时序和操作结果 |
| 3 校准与输入 | 桌面、袋体、手部、双手、按压、跟踪中断 | 原交互范围、阈值、恢复行为逐项真机对照 |
| 4 两套救援世界 | 模型材质、局部软体、三种玩法、能量、奖励、配音、Moodi | 完整双世界救援与原版视觉/时序对照通过 |
| 5 探索 | 糖果屋、自然藤蔓、触摸生长、散步、环境效果 | 各交互与空间关系一致 |
| 6 泡泡世界 | 入口、嵌套世界、点云、扰动、门与返回 | 正确进出、坐标连续、真机性能与视觉验收 |
| 7 许愿与收尾 | 手写、预设、风铃、日记、设置、教学 | 全流程与数据持久化完成 |
| 8 参赛交付 | 英文、离线、资源授权、AI 披露、体积、稳定性 | 提交包与真机完整回归通过 |

第一批开发仅建立工程和逻辑基础。原生空间中不放置替代性的球体或样例模型来声称已完成原视觉。模型转换要追溯 Unity 原始 FBX、材质和贴图；不读取手机版。
